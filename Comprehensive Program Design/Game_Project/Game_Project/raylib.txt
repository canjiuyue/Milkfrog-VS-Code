==============================================================================
                    raylib 6.2 API 函数参考手册（中文整理）
==============================================================================

整理依据：raylib 官方头文件 raylib.h（版本 6.2.0），共 619 个函数，
按官方模块（core / rgestures / rcamera / shapes / textures / text / models / audio）分组。

条目说明：
  · 所属模块：该函数在 raylib 中的官方模块。
  · 函数声明：C 语言原型（返回值 函数名(参数列表)）。
  · 功能/作用：该函数做什么（括号内为官方英文注释原文，便于对照官方文档）。
  · 调用方式：调用时机、配对关系与注意事项。

编译链接提示：
  1. 包含头文件：#include <raylib.h>
  2. 编译（Linux/macOS 示例）：gcc main.c -o main -lraylib -lGL -lm -lpthread -ldl -lrt
  3. Windows（MSYS2/MinGW）：gcc main.c -o main.exe -lraylib -lgdi32 -lwinmm
  4. 绘制类函数必须在 BeginDrawing()/EndDrawing()（2D）或
     BeginMode3D()/EndMode3D()（3D）之间调用；Load 与 Unload 必须配对。

------------------------------------------------------------------------------
【模块 core】核心模块（rcore）：窗口、图形设备、时间、文件、输入事件、自动化录制
------------------------------------------------------------------------------

模块调用总则：在 main() 开头先调用 InitWindow() 完成初始化；随后进入 while 主循环，循环体内以 BeginDrawing() 开始、EndDrawing() 结束；退出条件由 WindowShouldClose() 判断，结束前调用 CloseWindow()。文件、时间、日志等辅助函数可在任意时机调用。

[001] InitWindow
  所属模块：core
  函数声明：void InitWindow(int width, int height, const char *title);
  功能/作用：初始化相关子系统，须在使用其功能之前调用一次。
            官方注释：Initialize window and OpenGL context
  调用方式：程序开头、其他任何 raylib 调用之前调用一次；width/height 为窗口客户区尺寸（像素），title 为标题栏文本；返回后即可进入主循环。

[002] CloseWindow
  所属模块：core
  函数声明：void CloseWindow(void);
  功能/作用：关闭并释放对应子系统（窗口/音频设备）。
            官方注释：Close window and unload OpenGL context
  调用方式：主循环结束后调用一次，关闭窗口并释放 OpenGL 上下文；之后不要再调用其他 raylib 函数。

  调用方式：在音频流/管线初始化后挂载或移除处理器回调；回调签名见头文件注释。

【附录】独立数学模块 raymath.h（不属于 raylib.h，但随 raylib 6.2 一同发布）
------------------------------------------------------------------------------
raymath 提供 Vector2/Vector3/Vector4/Matrix/Quaternion 的运算函数（如向量加减、
点积、叉积、矩阵乘法、四元数旋转等），定义为 static inline，使用时：
  #include <raylib.h> 后再 #include <raymath.h>；它不依赖 raylib 即可独立编译。
完整函数清单参见官方头文件：src/raymath.h 或 raylib 官方文档 Math 模块。
